# transworld-sites
Private monorepo for the three TransWorld SG sites.

- apps/transworld: TransWorld SG Consulting (current site)
- apps/transco: Transco SG Group (Cameroon landing page), not started
- apps/services: Procurement & Sourcing + Property Services, not started
- packages/shared: shared code, not yet extracted

Each app is its own Vercel project: set Root Directory to apps/<name>. Env vars per app are listed in its .env.example.
